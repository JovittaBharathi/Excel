# Excel Assignments

## 📖 Overview
This repository contains a collection of Microsoft Excel assignments designed to strengthen spreadsheet skills, data analysis techniques, and practical business problem-solving abilities. The assignments cover essential Excel concepts ranging from basic formulas to advanced data management and visualization.

## 🎯 Objectives
- Learn and apply Excel formulas and functions.
- Perform data cleaning and validation.
- Analyze datasets using sorting and filtering techniques.
- Create PivotTables and Pivot Charts.
- Develop dashboards and reports for decision-making.
- Enhance spreadsheet productivity using Excel tools.

## 🛠️ Tools Used
- Microsoft Excel
- Excel Formulas & Functions
- PivotTables
- Pivot Charts
- Conditional Formatting
- Data Validation
- Charts & Graphs
